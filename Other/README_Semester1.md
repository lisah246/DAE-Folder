# Semester 1 – Foundations

## Focus
This semester focused on establishing the **core technical foundations** required for backend development and prompt engineering. Students practiced Unix, Python, and Logic, while also experimenting with AI-assisted project design.

## Key Work
- **Unix 1 & 2**: Command-line navigation, file operations, permissions, scripting basics  
- **Python 1 & 2**: Programming fundamentals, data types, loops, functions, error handling  
- **Logic 1**: Introductory computational logic, conditionals, and control flow  
- **Prompt Engineering 1**: Used AI to generate schedules, flowcharts, and project ideas  
- **Mini Project**: Tkinter-based survival adventure game with prompt iteration and flowcharts  

## Highlights
- Gained strong foundations in **programming and command-line environments**  
- Built and documented an **AI-assisted Tkinter survival game**  
- Practiced writing prompts, tracking AI responses, and debugging logic  
- Learned to document process with **flowcharts and iteration logs**
