# Semester 3 – Backend & Full-Stack Integration

## Focus
Developed the **Client & Project Management Dashboard with Role-Based Access Control**, a full-stack project connecting backend APIs with a professional frontend.

## Key Work
- **Backend (Node.js/Express + SQLite/Sequelize)**  
  - CRUD endpoints for projects, clients, tasks, notes, attachments  
  - Role-based access (Project Manager, Client, Developer)

- **Frontend (Next.js + ShadCN UI + Tailwind)**  
  - Dashboards with summary cards, project tables, and JIRA-style task boards  
  - Reports with charts and PDF export  
  - Client dashboards with comments and limited access  

- **Advanced Features**  
  - Notifications & reminders  
  - File upload/download with Multer  
  - Authentication with Auth.js  
  - Deployment to Vercel (frontend) & Netlify (backend)

## Tech Stack

**Languages**
- JavaScript (Node.js, React/Next.js)
- TypeScript (frontend)
- SQL (SQLite with Sequelize ORM)
- CSS (Tailwind CSS + TweakCN)

**Backend**
- Node.js + Express.js  
- Sequelize ORM with SQLite  
- Nodemailer for email  
- Multer for file uploads  

**Frontend**
- Next.js (React-based)  
- ShadCN UI components  
- Tailwind CSS + TweakCN  
- Chart.js/Recharts for reports  

**Deployment**
- Frontend: Vercel  
- Backend: Netlify Functions  
- Database: SQLite (with option to scale to PostgreSQL)  

## Highlights
- Built and tested a fully functional full-stack CRUD application  
- Integrated project reporting with charts + PDF export  
- Deployed a working live demo app online  
- Practiced full project lifecycle: planning → building → deploying → presenting
