# ADR 0001 — Stack & Deployment Choice
**Status:** Accepted  
**Date:** 2025-09-08

## Context
The project is a project/client/task dashboard with simple role-based views. Time is limited to ~1–2 hours/day. The school program forbids Postman and AWS. We need fast local dev, simple persistence, and easy demo deploys.

## Decision
- **Backend:** Node.js + Express
- **Database:** SQLite with Sequelize ORM
- **Frontend:** Next.js (React) + Tailwind + ShadCN UI
- **File handling:** Multer (local `/uploads`)
- **Reports/PDF:** Server-side JS PDF library
- **Notifications:** In-app (DB-backed), generated by backend routes
- **Deployment:** Backend via Netlify Functions; Frontend via Vercel
- **No:** Postman, AWS

## Consequences
- Super simple local setup (no DB server).
- Can meet SQL rubric with real tables/queries.
- Easy to host a demo quickly (Netlify/Vercel).
- Local file storage is fine for class demos; future cloud storage could be swapped later.
