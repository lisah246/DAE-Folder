## My Journey in Backend Development 🚀
I’m passionate about building robust server-side logic, scalable databases, and intuitive APIs that power modern web and mobile applications.

I bring a **product mindset** to engineering—always thinking about user impact, business outcomes, and cross-functional collaboration.

Currently pursuing a degree in **Backend Development** at DAE, graduating **December 2025**, I’m learning to design secure, data-driven systems that unlock human potential, drive meaningful business outcomes, and help teams ship faster and smarter.

I’m actively seeking a role as a **Backend Developer** collaborating with a tech-savvy, innovative team that values remote flexibility, bold thinking, and continuous learning — where I can help build the digital foundations of exceptional user experiences.

### Core Interests & Expertise

⚙️ **Server-Side Development**  
Building robust backend systems using Node.js and Express, with a focus on clean architecture and maintainable code.

🗄️ **Database Design & Management**  
Designing relational schemas and managing data with SQLite, including migrations, seeding, and query optimization.

🔐 **Authentication & Security**  
Implementing secure user authentication using JWT and bcrypt, with middleware for protected routes and role-based access.

🔗 **API Design**  
Creating RESTful APIs that connect frontend interfaces with backend logic, supporting CRUD operations and data aggregation.

📁 **File Handling & Local Storage**  
Developing endpoints for file uploads and retrieval, storing file paths in the database for project-linked assets.
